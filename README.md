# ICN292 – Proyecto SIG: Mass Café SPA

## 1. Descripción del proyecto
Este repositorio contiene el desarrollo de la Entrega 2 del proyecto de Sistemas de Información para la Gestión, realizado para la PYME Mass Café SPA, cuyo nombre comercial es La Cantina del Café.
El proyecto aborda la gestión de inventario de la cafetería y propone InventaFood, un sistema de información orientado a mejorar el control de productos e ingredientes, las entradas y salidas de inventario y la planificación de compras.

## 2. Problema identificado
Actualmente, las ventas se registran en Fudo, mientras que el inventario se controla mediante registros manuales. Esta falta de conexión dificulta conocer las existencias reales, genera revisiones que consumen tiempo y puede provocar compras de urgencia y pérdidas de productos.

## 3. Objetivo del proyecto
Proponer un sistema de información que permita mejorar la gestión de inventario, mantener actualizado el stock, registrar movimientos, identificar productos que necesitan reposición y apoyar las decisiones de compra.

## 4. Desarrollo de la Entrega 2
Durante esta entrega se desarrollaron los siguientes aspectos:
- Actualización de requerimientos y trazabilidad del proyecto.
- Modelamiento del proceso mediante BPMN.
- Diseño del modelo entidad-relación y normalización a tercera forma normal (3FN).
- Implementación de la base de datos en MySQL.
- Elaboración de datos de prueba y consultas SQL.
- Diseño de flujos de automatización mediante n8n.
- Documentación y organización de los archivos del proyecto.
